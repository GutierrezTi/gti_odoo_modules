Spanish Autonomo: Partial Deducibility

Manage non-deductible VAT and Expenses according to Spanish Tax Law

This module allows freelancers (Autónomos) in Spain to manage expenses where only a percentage of VAT or IRPF is deductible (e.g., vehicles, home supplies).

  • Set deducibility profiles (e.g., 50% for vehicles).
  • Assign default profiles to Partners or Products.
  • Automatic accounting reclassification (VAT to Expense/Asset).

Hierarchy & Automation

The system automatically suggests the best deduction profile by checking:

  1. The Partner (Vendor) settings.
  2. The Product template configuration.
